# Renura Kasir – cara membuat APK

## Cara 1: tanpa Android Studio (GitHub, gratis)
1. Buat repositori baru di github.com, lalu unggah SELURUH isi folder ini (termasuk folder .github).
2. Buka tab **Actions** → workflow **Build APK** → tunggu selesai (±5 menit).
3. Klik hasil run → bagian **Artifacts** → unduh **RenuraKasir-apk** → ekstrak, pasang file .apk di HP.
   (Izinkan "pasang dari sumber tidak dikenal".)

## Cara 2: Android Studio
Buka folder ini → tunggu sync → menu Build → Build APK(s).

## Catatan
- Cetak struk memakai printer Bluetooth yang sudah DIPASANGKAN di pengaturan Bluetooth HP (printer thermal 58 mm, ESC/POS).
- Fitur AI (scan produk, Tanya AI) hanya jalan di versi web Claude, tidak ada di APK ini.
- Data tersimpan di HP. Ekspor/cadangan masuk ke folder Download.
